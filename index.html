Chaves e acessos

Cadastre ou troque chaves de API sem editar arquivos manualmente no servidor.

As chaves são gravadas numa pasta privada da VPS. O painel não mostra novamente o valor depois de salvar. Cadastrar uma chave não configura automaticamente um programa: conecte o arquivo ao serviço que vai usá-la.

Conecte-se à VPS para conferir as chaves.

Cadastrar ou trocar chave

Para substituir, use exatamente o mesmo nome e informe a nova chave.

Não coloque chaves no GitHub ou em mensagens de chat. O nome deve conter apenas letras minúsculas, números e hífens.

Chaves cadastradas: —

Os valores ficam ocultos. É possível substituir ou excluir os arquivos.
